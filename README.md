# AI-Based Customer Churn Prediction System

## Project Overview

This project uses machine learning to predict whether a customer is likely to leave a service. It provides an interactive dashboard and a customer prediction interface built using Streamlit.

## Features

* Dataset preview and exploration
* Machine learning model training
* Customer churn prediction
* Churn probability estimation
* Interactive Streamlit interface

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* XGBoost
* Streamlit

## Machine Learning Algorithms

* Random Forest Classifier
* Decision Tree Classifier
* XGBoost Classifier

## Installation

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project folder:

   `cd AI-Customer-Churn-Prediction`

3. Install the dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
